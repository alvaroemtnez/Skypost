# 0018. Licence: AGPL-3.0-or-later

Status: accepted (2026-10-19). Replaces GPL-3.0-or-later.

## Context

Pharos is a network service: Signal, WhatsApp and MeshCore users talk to it
without ever receiving the software. Under the GPL, someone could run a
modified Pharos for others and keep the changes private. The project has one
copyright holder, so it can relicense freely.

## Decision

AGPL-3.0-or-later for the whole repository (app, core, Pharos, prototype).

## Consequences

- Whoever runs a modified Pharos must offer its source to the people using
  it over the network, including bridged contacts.
- Compatible with everything we use or plan to: MIT/Apache/BSD dependencies,
  and GPLv3 code (JS8Call's engine, Mercury) through section 13 of GPLv3 and
  AGPLv3. External programs run as separate processes (signal-cli, wacli,
  meshcore_py) are not affected.
- Contributions from others need to come under the same licence (or a CLA)
  to keep relicensing possible.
